## Examine the log dump file

In this lab, you will develop critical skills in analyzing system logs to identify patterns, anomalies, and potential security issues. Being able to interpret the vast amount of data in log files is an essential skill for any cybersecurity professional.

You have been provided a log dump file, which you should have placed in your <code class="filepath">log_dump.txt</code> file. This file contains real records from a large enterprise network.

This log covers a 24-hour period and includes a mix of normal traffic and suspicious activity. Your mission is to comb through this data to spot and document the issues lurking within.

The log is in standard Syslog format with the following fields:

- Timestamp
- Source IP
- Destination IP
- Protocol
- Port
- Action (Allow/Deny)
- Bytes Transferred

Take a few minutes to open the file and get acquainted with its structure and contents. Don't worry about analyzing it in depth yet; just aim to understand the kind of data it contains and how it's organized.
